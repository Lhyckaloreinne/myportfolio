# 01. Project Overview

## Short Description

TUGON is a mobile emergency response application designed for the Municipality of Paombong's MDRRMO. It enables residents to quickly report emergencies by automatically transmitting their real-time GPS location, helping responders coordinate faster and improve emergency response.

## Project Context

The Paombong MDRRMO previously relied on manual emergency reporting procedures, requiring responders to gather the caller's information and location before dispatching assistance. This process introduced delays during critical situations where every minute matters.

TUGON was designed to modernize this workflow by integrating GPS-based location sharing, emergency reporting, weather updates, and communication features into a single mobile application.

Although the overall project includes a web-based dashboard, my contribution focused solely on designing the resident-facing mobile application.

# 09. Key Design Decisions

## One-Tap Emergency Reporting

Residents may be under stress during emergencies. The reporting process was simplified to minimize the number of interactions required.

---

## Automatic GPS Location Sharing

Automatically transmitting the user's location eliminates the need for manual location reporting and improves response accuracy.

---

## Interactive Emergency Map

Displaying the user's location visually provides confidence that the correct location is being shared with responders.

---

## Simplified Mobile Experience

Only essential actions are emphasized to reduce cognitive load during emergencies.
